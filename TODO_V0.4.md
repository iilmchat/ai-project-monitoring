## 2. Принципы

1. **Маленькие итерации:** спринт = законченная UX-порция, `main` всегда зелёный.
2. **Read-only по умолчанию:** мутации только через `confirm=true` и `action_log`.
3. **Один факт — один источник:** SPEC — контракты, ARCHITECTURE — устройство, этот файл — план.
4. **Сначала состояние, потом рендер:** фильтры/сортировка/колонки — в store, не в компонентах.
5. **Сохраняемость:** пользовательские настройки (views/columns/selection) переживают перезагрузку.
6. **A11y не «потом»:** клавиатура и семантика входят в DoD каждого спринта.
7. **Никаких секретов в UI:** токены — только маски, Telegram token — в настройках/ENV.

### Спринт 21 — Visuals, A11y & New Features

**Задачи**
- **S21-001 A11y.** Иконки/форма к цветным бейджам (не только цвет): `✓ current`,
  `!` dirty, `↓` behind, `⚠` diverged, `?` no_upstream. `aria-label`, контраст
  WCAG AA, видимый focus-ring, `prefers-reduced-motion`.
- **S21-002 Stale Data Indicator.** Если `checked_at` старше TTL или
  `remote_status ∈ {stale, unavailable}` — приглушать блок (`opacity`), бейдж
  «Устарело» с tooltip «обновлено N минут назад».
- **S21-003 Conflict Manager.** Для `state="diverged"` — список конфликтующих файлов
  через `git diff --name-only --diff-filter=U` (read-only), панель в деталях
  репозитория; ссылки на файлы не открываются автоматически.
- **S21-004 Telegram Webhooks.** Замена `plyer` на Bot API:
  `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `NOTIFICATIONS_CHANNEL=telegram|desktop`.
  Retry/backoff, rate-limit; токены — в Settings (маскируются) или ENV.
- **S21-005 Contribution Heatmap.** Активность коммитов за 365 дней по всем
  репозиториям (агрегация `git log --since`), lazy-компонент, кэш 10 минут.
- **S21-006 Data Export.** Экспорт текущего среза таблицы в CSV/JSON (клиентская
  генерация из уже загруженных данных; без новых серверных отчётов).

**DoD:** бейджи различимы без цвета; stale-состояние видно; conflict-файлы
показываются для diverged; Telegram-уведомление уходит на тестовый чат (mock в тестах);
heatmap и экспорт не раздувают entry bundle (lazy).

## 5. Риски

| Риск | Вероятность | Влияние | Митигация |
|------|-------------|---------|-----------|
| Раздувание entry bundle (recharts, heatmap, palette) | Высокая | Среднее | lazy + code-splitting, бюджет 100 kB gzip |
| Сложность синхронизации saved views (local vs DB) | Средняя | Среднее | версионированная схема, localStorage в v0.4, БД — v0.5 |
| Регрессии клавиатурной навигации | Средняя | Среднее | единый `useHotkeys`, интеграционные тесты |
| A11y-долг | Средняя | Высокое | иконки/aria в DoD каждого спринта |
| Telegram API rate-limit/секреты | Средняя | Среднее | retry/backoff, токен только в Settings/ENV |
| Conflict Manager читает только unmerged-файлы | Низкая | Низкое | документировать ограничение (не заменяет `git status`) |
| Batch-операции на сотнях репозиториев | Средняя | Высокое | concurrency 5, отмена/прогресс в v0.4.1 |
