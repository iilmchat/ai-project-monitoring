## 1. Зачем v0.8.0

v0.7.0 доказал, что приложение умеет собирать данные и подключать локальный LLM.
Следующий шаг — сделать эти данные **действенными**: меньше кликов до ответа
«что делать», корректные зависимости в монорепозиториях, AI-рекомендации на
каждом экране, понятные связи между клонами одного проекта и переносимые
AI-провайдеры.

### Цели

| # | Цель | Критерий достижения |
|---|------|---------------------|
| G1 | Зависимости видны всегда | Python/Node манифесты находятся во вложенных каталогах (`backend/`, `frontend/`) |
| G2 | Рекомендации — первый экран | Блок рекомендаций выше вторичных секций; после действия данные и рекомендации обновляются |
| G3 | Дашборд ведёт к действию | Клик по «9 требуют внимания» открывает уже отфильтрованный список |
| G4 | Меньше визуального шума | Фильтры и вторичные секции свёрнуты по умолчанию; дашборд всегда виден |
| G5 | Два языка | RU/EN переключатель в шапке, выбор сохраняется, даты/числа локализованы |
| G6 | Global Dependencies полезен | Закладки экосистем, переходы в проекты, информация об унификации в карточке проекта |
| G7 | AI помогает, а не мешает | AI-рекомендации на главной, в строке репозитория и в карточке; tooltips и дисклеймеры |
| G8 | Один проект — один идентификатор | Клоны `ai-teacher_python` (GitHub/GitFlic) распознаются как связанные |
| G9 | Провайдеры AI переносимы | OpenAI-совместимые профили: local, DeepSeek, OpenRouter, Yandex, GigaChat, GPtunnel и др. |
| G10 | Задача для агента в один клик | Экспорт структурированной задачи для DSH/OpenCode без записи в чужой проект |

### Принципы

1. **Deterministic first, AI second.** Сначала правила и факты, потом LLM.
2. **Read-only по умолчанию.** Генерация README/рекомендаций/задач ничего не
   меняет; запись — только по явному подтверждению.
3. **AI не источник истины.** Любая AI-рекомендация подписана моделью и
   содержит дисклеймер; действия выполняет человек.
4. **Секреты не уходят.** Токены и diff не логируются; remote-провайдеры
   включаются только явным opt-in.
5. **Один факт — один источник.** SPEC — контракты, ARCHITECTURE — устройство,
   TODO — план, ADR — причины.
6. **Никаких новых зависимостей без ADR.** i18n и markdown-рендер — внутренние,
   без новых пакетов; HTTP — существующий `httpx`.
7. **Доступность и tooltips — часть контракта.** Все новые иконки/сокращения
   имеют `title`/`aria-label`, новые контролы — клавиатурные.

### Спринт 35 — Data Correctness & Repository Context (✅ Завершён 2026-11-07)

- [x] **S35-001. Вложенные манифесты.**
  - `ManifestDiscovery`: поиск `requirements.txt` и `package.json` до
    `DEPENDENCY_MANIFEST_MAX_DEPTH` (default 3), игнор `node_modules`, `.venv`,
    `venv`, `dist`, `build`, `target`, `.git`, `vendor`, кэшей.
  - `DependencyService` и `SecurityService` используют один discovery-слой.
  - Дедупликация пакетов по имени: exact > range с версией > range без версии.
  - В отчёт добавляется `manifests: string[]` и `manifest_path` у пакета;
    `manifest` остаётся совместимым (первый/объединённый).
  - UI: показывать список найденных манифестов и путь пакета в tooltip.
  - Тесты: `backend/requirements.txt` + `frontend/package.json`, дубли,
    игнор `node_modules`, лимит глубины, security использует те же манифесты.

- [x] **S35-002. README и документы проекта.**
  - `GET /repositories/{id}/readme` → `{name, version, path, content}`;
    парсинг H1 и `Версия/Version` + badge-версий.
  - `GET /repositories/{id}/docs?path=docs/SPEC.md` → Markdown внутри репозитория.
  - Защита: только `.md/.markdown/.txt`, путь внутри repo root, лимит 512 KiB,
    запрет `.git`, `..`, абсолютных путей.
  - UI: компактная «визитка» проекта под заголовком (название из README +
    version-chip + путь + кнопка README).
  - Модалка README: безопасный Markdown-рендер, внутренние ссылки открывают
    другой документ, кнопка «Назад» возвращает по стеку, внешние ссылки — в
    новой вкладке.
  - Тесты: парсинг версии, traversal, отсутствие README, переход по ссылке.

- [x] **S35-003. Рекомендации — наверх и всегда свежие.**
  - Блок «Рекомендации» сразу после карточек «Репозиторий»/«Статус», до CI.
  - После подтверждённого действия: сначала обновить статус, затем
    последовательно перезагрузить рекомендации, коммиты, зеркало, историю.
  - Не использовать `Promise.all` для refresh → recommendations (гонка).
  - Показывать результат действия и toast; ошибки не терять.

- [x] **S35-004. `arhiv-del` и ручное отслеживание.**
  - Объяснить: репозиторий был снят с tracking вручную для демонстрации
    раздела «Не отслеживаются», это не ошибка discovery.
  - Вернуть `arhiv-del` в tracked; остальные оставить как пример.

**DoD:** зависимости монорепозитория видны (Python и Node), README открывается
из карточки, рекомендации сверху и обновляются после действия, тесты/ruff/mypy
зелёные.

### Спринт 36 — Dashboard Interaction & i18n (RU/EN) — ✅ Завершён (2026-11-08)

- [x] **S36-001. Progressive disclosure.** *(фильтры и аналитика сворачиваются; persist/«развернуть всё» — далее)*
  - Фильтры, массовые действия, колонки, представления и вторичные блоки
    свёрнуты по умолчанию; состояние хранить в `localStorage`.
  - Дашборд (сводка + список) виден всегда; «Развернуть всё» / «Свернуть всё».
- [x] **S36-002. Кликабельные карточки сводки.** *(все пять карточек и scroll готовы)*
  - «Требуют внимания» → `status=dirty,ahead,behind,diverged,no_upstream`.
  - «Чистые» → `status=current`; «Не отслеживаются» → `tracked=false`;
    «Зеркала расходятся» → `mirror=<attention-statuses>`.
  - URL — источник состояния; после клика плавный scroll к «Репозитории».
- [x] **S36-003. Терминология и графики.** *(группа «Репозитории», подписи фильтров и графиков, tooltips на новых контролах)*
  - Заголовок группы: «Репозитории · 25».
  - Человеческие подписи: `current → чистый`, `behind → отстаёт`,
    `ahead → впереди`, `dirty → есть изменения`, `diverged → расходится`,
    `no_upstream → нет upstream`, `untracked → не отслеживается`.
  - Графики используют те же подписи; легенда зеркал — без `value`.
- [x] **S36-004. i18n RU/EN без внешних зависимостей.**
  - `I18nProvider`, `useI18n`, typed dictionaries, `localStorage` ключ.
  - Переключатель RU/EN рядом с темой, `document.documentElement.lang`.
  - Переводы всех страниц/компонентов, даты и числа через `Intl`.
  - Tooltips и aria-label переводятся вместе с текстом.
- [ ] **S36-005. Tooltips.** *(частично: title/aria для новых контролов; единый Tooltip — далее)*
  - Единый `Tooltip`/`InfoHint` (title + aria-describedby), подсказки к
    статусам, метрикам, AI-кнопкам, лимитам, правам и опасным действиям.

**DoD:** язык переключается без перезагрузки, выбор сохраняется, все видимые
строки локализованы, фильтры свёрнуты, карточки ведут в отфильтрованный список,
графики и таблицы используют человеческие подписи.

- [x] **S37-004. Связанные репозитории/дубли.**

## 5. Риски

| Риск | Вероятность | Влияние | Митигация |
|------|-------------|---------|-----------|
| Вложенные манифесты замедляют отчёт | Средняя | Среднее | Лимит глубины, ignore-лист, кэш, concurrency |
| Дубли определены ложно | Средняя | Среднее | Показывать «возможная связь», не объединять автоматически |
| README содержит небезопасный Markdown | Средняя | Высокое | Собственный безопасный рендер, без raw HTML, лимит размера |
| AI-провайдер утекает код | Низкая | Высокое | Только агрегаты, remote opt-in, маскировка, no prompt logs |
| i18n ломает тесты/тексты | Высокая | Низкое | Typed keys, fallback RU, snapshot-тесты ключей |
| GigaChat OAuth отличается от OpenAI | Высокая | Среднее | Отдельный adapter, mock-тесты, явный статус |
| Agent-task воспринимается как приказ | Средняя | Среднее | Явный preview, копирование, никакого автозапуска |
| Рост UI-сложности | Средняя | Среднее | Progressive disclosure, tooltips, сохранение состояния |

## 6. Best practices, которых пока не хватает (и что делаем)

| Область | Сейчас | Best practice v0.8 |
|---------|--------|--------------------|
| Зависимости | только root-манифесты | discovery вложенных манифестов + provenance |
| Идентичность репозитория | path/имена | remote identity + duplicate/mirror groups |
| AI-провайдеры | один `llm_*` | профили, default/per-feature, health-check |
| AI-наблюдаемость | базовые логи | метрики latency/tokens/cache/errors по провайдеру |
| AI-качество | нет eval | golden-set для commit/CVE/recommendations |
| i18n | только RU | RU/EN, Intl, persisted locale |
| Доступность | частично | tooltips, aria, keyboard, focus-trap в модалках |
| README/доки | нет | безопасный viewer с навигацией |
| Задачи агентам | нет | структурированный экспорт DSH/OpenCode |
| Безопасность секретов | маскировка | запрет промптов с секретами, remote opt-in, audit |
| Наблюдаемость фич | метрики есть | метрики по новым AI/README/duplicate-операциям |
| Данные | SQLite | резервное копирование/экспорт (v0.9) |
